Truthy & Falsy Values

Everything or every values in javascript is true or false in boolean context

List of falsy values

  • false
  • 0
  • -0
  • 0n (big int value)
  • "" (empty string)
  • null
  • undefined
  • NaN

Except falsy values, rest all values are treated as truthy values.

Common Methods

Common JavaScript Methods for Interaction

  • alert(message) – Displays a popup alert box with a message.
  • prompt(message) – Asks the user for input and returns it as a string.
  • confirm(message) – Shows a dialog box with OK and Cancel buttons, returning true or false.

Common JavaScript Methods for Debugging

  • console.log(message) – Prints general information to the browser’s developer console.
  • console.warn(message) – Prints a warning message to the console.
  • console.error(message) – Prints an error message to the console.

Operators in JS

There are mainly 3 types of Operators

  • unary
  • binary
  • ternary

Unary operators

  • Unary ( + )
  • unary ( - )
  • pre & post increment ( ++ )
  • pre & post decrement ( -- )
  • logical NOT ( ! )
  • bitwise NOT ( ~ )
  • typeof
  • delete
  • void

Binary operators

  • Arithmetic operators

      • +, -, *, /, %, **

  • Assignment Operators

      • +=, -=, *=, /=, %=, **=

  • Comparison Operators

      • == (loose equals), === (strict equals), !=, !==, >, >=, <, <=

  • Logical Operators

      • &&, ||

  • Bitwise Operators

      • &, |, ^, <<,>>, >>>

  • Some Special Operators

      • in, instanceof, ?. (optioanl chaining), ?? (nullish coaelscing)
