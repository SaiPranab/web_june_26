Truthy & Falsy Values

Everything or every values in javascript is true or false in boolean context

List of falsy values

  • false
  • 0
  • -0
  • 0n (big int value)
  • "" (empty string)
  • null
  • undefined
  • NaN

Except falsy values, rest all values are treated as truthy values.

global scope & script scope

- The variables which are declared directly in the js file or (outside any function) have global scope.

- Specificly the variables which are declared with var keyword & the functionk declaration are present inside the global scope & the variables or functions declared with let & const are present inside the script scope.

local or function scope

- The variables are which are declared within a function have local scope or function scope

- It means we can only access the variables within that particular function

Block Scope

- On the otherhand the variables which are declared within any block have block scope.

Lexical Scope

- When we write a function inside another function, it can access & use the variables of it's outer function

Scope Chaining

- When a variable is accessed within a function, Javascript looks for that variable in the current function scope, then it's parent function scope, and so on upto the global scope. This forms Scope Chaining

JavaScript Objects

Object in JavaScript

- An Object is a collection of key-value pairs used to store related data and functionalities in JavaScript.

Ex -
let student = {
  name: "Rahul",
  age: 21
};

Object Methods

- A function defined inside an object is called an Object Method. It is used to perform operations using the object's properties.

Ex -
let person = {
  name: "Amit",
  greet: function() {
    return "Hello";
  }
};

Nested Object

- A Nested Object is an object that contains another object as one of its properties. It is used to organize related data in a structured way.

Ex -
let student = {
  name: "Rahul",
  age: 20,
  address: {
    city: "Hyderabad",
    state: "Telangana"
  }
};

console.log(student.address.city);
// Output: Hyderabad

const Object

- When an object is declared using const, its reference cannot be reassigned, but its properties can be added, updated, or deleted.

Ex -
const user = { name: "Raj" };
user.age = 22;  // Allowed
user.name = "Rohan";  // Allowed
// user = {}; Not Allowed

Object.seal()

- Object.seal() prevents adding or deleting properties from an object, but existing properties can still be updated.

Ex -
let obj = { name: "John" };
Object.seal(obj);
obj.name = "David";  // Allowed
obj.age = 25;  // Not Allowed
delete obj.name;  // Not Allowed

Object.freeze()

- Object.freeze() makes an object completely immutable. Properties cannot be added, deleted, or modified.

Ex -
let emp = { name: "Sam" };
Object.freeze(emp);
emp.name = "Alex";  // Not Allowed
emp.age = 30;  // Not Allowed
delete emp.name;  // Not Allowed JavaScript Arrays

Array in JavaScript

- An Array is a special object used to store multiple values in a single variable. Each value is stored at an index, starting from 0.

Ex -
let fruits = ["Apple", "Banana", "Mango"];
console.log(fruits[0]); // Apple

Array Methods

- Array Methods are built-in functions used to add, remove, search, modify, or iterate over array elements.

push(element1, element2, ..., elementN)

- push() adds one or more elements to the end of an array and returns the new length.

pop()

- pop() removes the last element from an array and returns the removed element.

unshift(element1, element2, ..., elementN)

- unshift() adds one or more elements to the beginning of an array.

shift()

- shift() removes the first element from an array and returns the removed element.

includes(searchElement, fromIndex)

- includes() checks whether an element exists in an array and returns true or false.

indexOf(searchElement, fromIndex)

- indexOf() returns the index of the first occurrence of an element. If the element is not found, it returns -1.

lastIndexOf(searchElement, fromIndex)

- lastIndexOf() returns the last index of an element. If the element is not found, it returns -1.

slice(start, end)

- slice() returns a new array containing selected elements without changing the original array.

splice(start, deleteCount, item1, item2, ...)

- splice() adds, removes, or replaces elements in an array by modifying the original array.

concat(array1, array2, ...)

- concat() joins two or more arrays and returns a new array.

join(separator)

- join() converts all array elements into a string using a specified separator.

reverse()

- reverse() reverses the order of elements in the original array.

sort()

- sort() sorts the elements of an array. By default, it sorts elements as strings.

forEach(callbackFn)

- forEach() executes a callback function once for each array element. It does not return a new array.

map(callbackFn)

- map() creates a new array by applying a callback function to every element of an array.

filter(callbackFn)

- filter() creates a new array containing only the elements that satisfy a given condition.

some(callbackFn)

- some() checks whether at least one element in an array satisfies a given condition. It returns true if any element matches; otherwise, it returns false.

every(callbackFn)

- every() checks whether all elements in an array satisfy a given condition. It returns true only if every element matches; otherwise, it returns false.

find(callbackFn)

- find() returns the first element that satisfies a given condition. If no element matches, it returns undefined.

findIndex(callbackFn)

- findIndex() returns the index of the first element that satisfies a given condition. If no element matches, it returns -1.

reduce(callbackFn, initialValue)

- reduce() reduces all array elements to a single value by executing a callback function.

arguments Keyword

- The arguments keyword is an array-like object available inside regular functions. It contains all the arguments passed to the function.

- It can access arguments using index values, but it is not available in arrow functions.

- It does not uses Array methods such as map, filter, reduce.

Ex -
function sum() {
  console.log(arguments);
  console.log(arguments[0]);
}

sum(10, 20, 30);

Rest Parameters (...args)

- Rest Parameters collect multiple function arguments into a single array.

- It is represented using ... and must always be the last parameter of the function.

Ex -
function sum(...nums) {
  console.log(nums);
}

sum(10, 20, 30, 40); // [10, 20, 30, 40]

Spread Operator (...)

- The Spread Operator (...) is used to expand an iterable (like Array, String, Map, Set, etc.) into individual elements.

- It is mainly used to copy arrays/objects, merge arrays/objects, and pass array elements as function arguments.

Ex -
let arr1 = [10, 20];
let arr2 = [...arr1, 30, 40];

console.log(arr2); // [10, 20, 30, 40]
