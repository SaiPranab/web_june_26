Asynchronous JavaScript

- Asynchronous Javascript is a an ability to handle multiple operations without blocking the main thread.

- As Js is single threaded means it can only perform one task at a time.

- But with Asynchronous Programming we can schedule tasks to be executed later by Javascript engine.

Callback Hell

- Callback Hell is a situation in javascript where multiple nested Callbacks are used to handle Asynchronous operations

- It occurs when one callback depends on the result of the previous callback, which leads to deeply nested callback functions

Promises In JS

- A Promise in JavaScript is an object that represents the eventual completion (or failure) of an asynchronous operation and its resulting value.

- It allows us to write asynchronous code that is more readable and manageable, avoiding the "callback hell" that often occurs with deeply nested callbacks.

A Promise have 3 states

  • pending:- The initial state, neither fulfilled nor rejected.

  • resolve (or fulfill):- The operation completed successfully, and the promise has a resulting value.

  • reject:- The operation failed, and the promise has a reason for the failure (typically an error object).

then() & catch() method in Promises

  • then():- When a promise is resolved, then() is automatically executed.
  • catch():- When a promise is rejected, catch() is automatically executed.
