for...of Loop

- The for...of loop is used to iterate over the values of iterable objects such as Arrays, Strings, Maps, and Sets.

- It returns each element directly without using indexes.

- It cannot be used directly with plain objects.

Ex -
let fruits = ["Apple", "Banana", "Mango"];

for (let fruit of fruits) {
  console.log(fruit);
}

// Apple
// Banana
// Mango

for...in Loop

- The for...in loop is used to iterate over the keys (property names) of an object.

- To get the value, use object[key] or object.key.

Ex -
let student = {
  name: "Amiya",
  age: 20,
  course: "BCA"
};

for (let key in student) {
  console.log(key, student[key]);
}

Object.keys()

- Object.keys() returns an array containing all the keys (property names) of an object.

- The returned array can be used with array methods like map(), filter(), and forEach().

Ex -
let student = {
  name: "Aju",
  age: 21,
  course: "MCA"
};

console.log(Object.keys(student));
// ["name", "age", "course"]

Object.values()

- Object.values() returns an array containing all the values of an object.

- The returned array can be used with array methods like map(), filter(), and forEach().

Ex -
let student = {
  name: "Nikhil",
  age: 22,
  course: "B.Tech"
};

console.log(Object.values(student));
// ["Nikhil", 22, "B.Tech"]

Object.entries()

- Object.entries() returns an array of an object's key-value pairs.

- Each element of the returned array is a nested array containing a key and its corresponding value.

- It is commonly used with for...of and array destructuring.

Ex -
let student = {
  name: "Sarthak",
  age: 23,
  course: "M.Tech"
};

for (let [key, value] of Object.entries(student)) {
  console.log(key, value);
}
