Document Object Model (DOM) in JS

- DOM stands for Document Object Model.

- The DOM represents an HTML document as a tree of objects.

- Using JavaScript, we can access, modify, create, and remove HTML elements through the DOM.

Document

- The document object represents the complete HTML document loaded in the browser.

eg: console.log(document)

- We can use the document object to access HTML elements and perform different DOM operations.

eg: document.title

document.children

- The children property returns the direct child elements of an element.

- It returns an HTMLCollection.

eg: document.children

- In a normal HTML document, the collection generally contains the <html> element.

eg: document.children[0] // <html>...</html>

innerText

- The innerText property is used to get or set the visible text of an HTML element.

eg: element.innerText

- We can also change the text of an element.

eg: element.innerText = "Hello World"

innerHTML

- The innerHTML property is used to get or set the HTML content inside an element.

eg: element.innerHTML

- It returns the HTML markup contained inside the element.

- We can also change the text of an element.

eg: element.innerHTML = "<strong>Hello</strong>"

textContent

- The textContent property is used to get or set the text content of an HTML element.

eg: element.textContent

- It returns all the text content inside an element, including text that may not be visible on the page.

- We can also change the text content of an element.

eg: element.textContent = "Hello World"

Difference Between innerText, textContent and innerHTML

- innerText returns the visible/rendered text of an element.

- textContent returns all text content of an element, including text that may not currently be visible.

- innerHTML returns the HTML markup inside an element.

For example:

<div>Hello <strong style="display: none;">World</strong></div>

  • innerText → Hello
  • textContent → Hello World
  • innerHTML → Hello <strong style="display: none;">World</strong>

Selecting Elements

- JavaScript provides different methods to select HTML elements from the DOM.

getElementsByTagName()

- The getElementsByTagName() method selects elements using their HTML tag name.

- It returns an HTMLCollection.

eg: document.getElementsByTagName("p") // All <p> elements in the document.

getElementsByClassName()

- The getElementsByClassName() method selects elements using their class name.

- It returns an HTMLCollection.

eg: document.getElementsByClassName("box") // elements having the class box.

getElementById()

- The getElementById() method selects an element using its id.

- It returns a single element or null if no matching element is found.

eg: document.getElementById("heading") // The element having id="heading".

querySelector()

- The querySelector() method selects the first element that matches a CSS selector.

eg: document.querySelector(".box") // The first element having the class box.

eg: document.querySelector("#heading") // The first element having the ID heading.

querySelectorAll()

- The querySelectorAll() method selects all elements that match a CSS selector.

- It returns a NodeList.

eg: document.querySelectorAll(".box") // All elements having the class box.

Getting and Setting Attributes

- HTML elements can have attributes such as id, class, href, src, and title.

getAttribute()

- The getAttribute() method is used to get the value of an attribute.

eg: element.getAttribute("id") // The value of the id attribute.

setAttribute()

- The setAttribute() method is used to add a new attribute or change an existing attribute.

eg: element.setAttribute("title", "Hello") // The element gets the attribute title="Hello".

removeAttribute()

- The removeAttribute() method is used to remove an attribute from an element.

eg: element.removeAttribute("title") // The title attribute is removed.

Applying Styles

- JavaScript provides different ways to apply CSS styles and classes to HTML elements.

style

- The style property is used to apply inline CSS styles directly to an element.

eg: element.style.color = "red"

eg: element.style.backgroundColor = "yellow"

className

- The className property is used to get or replace the complete value of the class attribute.

eg: element.className = "box active"

- Assigning className replaces the existing class value.

classList.add()

- The classList.add() method adds one or more classes to an element.

eg: element.classList.add("active")

- Existing classes are not removed.

classList.remove()

- The classList.remove() method removes one or more classes from an element.

eg: element.classList.remove("active")

classList.toggle()

- The classList.toggle() method adds a class if it does not exist and removes it if it already exists.

eg: element.classList.toggle("active")

Accessing Parent and Sibling Elements

- DOM navigation allows us to move from one element to its parent or sibling elements.

parentElement

- The parentElement property returns the parent HTML element of the current element.

eg: element.parentElement

nextElementSibling

- The nextElementSibling property returns the next sibling that is an HTML element.

eg: element.nextElementSibling

previousElementSibling

- The previousElementSibling property returns the previous sibling that is an HTML element.

eg: element.previousElementSibling

nextSibling

- The nextSibling property returns the next sibling node.

- Unlike nextElementSibling, it can return a text node, such as whitespace between HTML elements.

eg: element.nextSibling

Adding Elements

append()

- The append() method adds content at the end of an element.

- It can add elements as well as plain text.

- It can also accept multiple arguments.

eg: element.append("Hello")

eg: element.append(childElement)

appendChild()

- The appendChild() method adds a single node as the last child of an element.

eg: element.appendChild(childElement)

prepend()

- The prepend() method adds content at the beginning of an element.

- It can add elements as well as plain text.

eg: element.prepend("Hello")

Creating Elements

createElement()

- The createElement() method creates a new HTML element.

- The newly created element is not automatically added to the document.

eg: let div = document.createElement("div")

- We can add the newly created element to the document using append() or appendChild() or prepend().

eg: document.body.append(div)

Removing Elements

remove()

- The remove() method removes an element from the DOM.

eg: element.remove() // The element is removed from the document.

insertAdjacentHTML()

- The insertAdjacentHTML() method inserts HTML at a specified position relative to an element.

eg: element.insertAdjacentHTML("beforeend", "<p>Hello</p>")

- It accepts four positions:

  • beforebegin
  • afterbegin
  • beforeend
  • afterend

insertAdjacentElement()

- The insertAdjacentElement() method inserts an existing HTML element at a specified position.

eg: element.insertAdjacentElement("beforebegin", newElement)

- The position can be

  • beforebegin
  • afterbegin
  • beforeend
  • afterend

insertAdjacentText()

- The insertAdjacentText() method inserts plain text at a specified position relative to an element.

eg: element.insertAdjacentText("beforeend", "Hello World")

- The provided content is treated as plain text and is not interpreted as HTML.

closest()

- The closest() method searches upward through the DOM tree and returns the nearest element that matches a specified CSS selector.

- The element on which closest() is called is also checked.

eg: element.closest(".container")

Result: The nearest element matching the .container selector.

Summary

- DOM allows JavaScript to communicate with and manipulate HTML documents.

- We can select elements using methods such as getElementById(), querySelector(), and querySelectorAll().

- We can change content using innerText, textContent, and innerHTML.

- We can manipulate attributes using getAttribute(), setAttribute(), and removeAttribute().

- We can modify styles and classes using style, className, and classList.

- We can navigate through the DOM using properties such as parentElement, nextElementSibling, and previousElementSibling.

- We can create, insert, and remove elements using methods such as createElement(), append(), prepend(), remove(), and insertAdjacentHTML().
