Function Expression

- When a function is assigned to a variable that is called as Function Expression

Anonymous Function

- When a function having no name that is called as Anonymous Function

- Except function declaration, in all other ways we can use anonymous function to define a function

Arrow Function

- Arrow function is a shorter way of defining a function by following the syntax:-

() => {return;}
ex:- i) (a, b) => { return a + b }
ii) (a, b) => a + b

IIFE (Immediately Invocable Function Expression)

- When a javascript function runs immeditaly after its definition, that is called as IIFE.

i) (function (){ // body })(); ii) (() => { })();
