Object in JavaScript

- An Object is a collection of key-value pairs used to store related data and functionalities in JavaScript.

Ex -
let student = {
  name: "Rahul",
  age: 21
};

Object Methods

- A function defined inside an object is called an Object Method. It is used to perform operations using the object's properties.

Ex -
let person = {
  name: "Amit",
  greet: function() {
    return "Hello";
  }
};

Nested Object

- A Nested Object is an object that contains another object as one of its properties. It is used to organize related data in a structured way.

Ex -
let student = {
  name: "Rahul",
  age: 20,
  address: {
    city: "Hyderabad",
    state: "Telangana"
  }
};

console.log(student.address.city);
// Output: Hyderabad

const Object

- When an object is declared using const, its reference cannot be reassigned, but its properties can be added, updated, or deleted.

Ex -
const user = { name: "Raj" };
user.age = 22;  // Allowed
user.name = "Rohan";  // Allowed
// user = {}; Not Allowed

Object.seal()

- Object.seal() prevents adding or deleting properties from an object, but existing properties can still be updated.

Ex -
let obj = { name: "John" };
Object.seal(obj);
obj.name = "David";  // Allowed
obj.age = 25;  // Not Allowed
delete obj.name;  // Not Allowed

Object.freeze()

- Object.freeze() makes an object completely immutable. Properties cannot be added, deleted, or modified.

Ex -
let emp = { name: "Sam" };
Object.freeze(emp);
emp.name = "Alex";  // Not Allowed
emp.age = 30;  // Not Allowed
delete emp.name;  // Not Allowed
